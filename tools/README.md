# Hub browser checks

These Playwright scripts check the live www.govassured.com features (outages, publications, the government map, glossary tooltips, and the home-page link). They are not run by GitHub Actions.

```bash
python3 -m http.server 8000   # from the repository root
cd tools && npm install
B=http://127.0.0.1:8000 SHOTS=./shots node e2e-home-govmap.js
```

`B` is the site under test (local, preview, or production). `SHOTS` defaults to `tools/shots/` and is gitignored. `CHROME` can point at a Chrome or Chromium binary; the default is `/usr/bin/google-chrome`.

`e2e-architect.js` checks the Security Architect Corner (`/architect/`): the phase accordion (mouse and keyboard), link targets, heading order, no horizontal scroll at 1440px and 390px, and no console or CSP errors. It also checks the Documents for this phase box in each phase and the What you produce links. Set `HOME_TILE=1` only when the build under test links the page from the home page.

`e2e-architect-beginners.js` checks the beginner path: the overview at `/architect/beginners/` and each of the seven step pages load (slashless too on hosted environments), the Start here card on `/architect/` links to the overview in the same tab, Previous/Next and breadcrumbs work, each step has a pauseable explainer animation that honours `prefers-reduced-motion`, a What GOV.UK recommends box, and (except the final exercise) a check-your-understanding question, progress ticks persist from a step page to the overview in localStorage, YouTube and official guidance links open in a new tab with `noopener noreferrer`, there is no sideways scroll at 1440px and 390px, and axe-core 4.14.1 reports no violations in desktop, mobile and a light color-scheme pass.

`e2e-start.js` checks the Start your security journey path: the overview at `/start/` and each of its eight step pages load (slashless too on hosted environments), the home tile, the Corner Start here card and the beginner architecture path all point at it in the same tab, Previous/Next and breadcrumbs work (step 8 hands over to `/architect/beginners/`), each step has a pauseable explainer animation that honours `prefers-reduced-motion`, a What GOV.UK recommends box, a try-it box and a check-your-understanding question, each of the 14 video clips (exact start times) has a What this video covers explainer with 3 to 6 bullets and an SVG infographic with a title and description, progress ticks persist under their own localStorage key, YouTube and official guidance links open in a new tab with `noopener noreferrer`, nothing but YouTube, gov.uk and the two allowed company links leaves the site, there are no personal names and one footer disclaimer, no sideways scroll at 1440px and 390px, and axe-core 4.14.1 reports no violations in desktop, mobile and a light color-scheme pass. `scripts/check_start_pages.py` runs from `scripts/build.sh` and checks the pages, sitemap, rewrites and link allowlist agree. The pages are generated by `scripts/build_start_path.py` from `scripts/start_path_content.py` and `scripts/start_path_steps.py`.

`e2e-architect-templates.js` checks the template list at `/architect/templates/` and each of the ten template pages: breadcrumb, previous and next links, worked examples fill in, answers save to localStorage and come back after a reload, risk and RACI rows add and remove, print shows only the chosen template, `.doc` and `.md` downloads contain the answers, no requests other than same-origin GETs, and WCAG 2.2 AA with the templates empty and filled. Set `DOCSHOTS=dir` to also save screenshots of the four lifecycle templates filled in. It also checks the "Official template" or "Guidance this follows" inset on each page (new-tab links with a hidden label, file type and size on file links, the OGL v3 attribution only where it applies), the "Aligned with official template" tags on the list, that exports use the new fields and credit the official template, and that answers saved by the previous layout (version 1) are migrated to the new fields under the same `ga-arch-tpl-v1-<key>` keys. Set `OFFSHOTS=dir` to save screenshots of the list with tags and of the decision record and supplier pages with their inset. Screenshots go to `SHOTS` (default `tools/shots/templates/`).

The template pages under `architect/templates/` are generated by `scripts/build_architect_templates.py`. The document trail page and the Documents for this phase boxes on `/architect/` are generated by `scripts/build_architect_doc_trail.py` from one matrix. Run them in that order, then `scripts/bust_govmap.py`. `scripts/build.sh` runs `scripts/check_architect_pages.py`, which fails if a page is missing from the sitemap, the rewrites or the link check.

`e2e-architect-patterns.js` checks the patterns list at `/architect/patterns/` and each of the five pattern pages: breadcrumb, all sections, the diagram (zones, labelled links, text description, fits at 390px), CAF and NCSC mappings, related templates and tools, previous and next links, new-tab labels on outside links, no horizontal scroll, no console or CSP errors and WCAG 2.2 AA. The pages are generated by `scripts/build_architect_patterns.py` (then run `scripts/bust_govmap.py`).

`e2e-architect-doc-trail.js` checks `/architect/document-trail/`: the table matches the approved matrix, has a caption and row and column headers, sits in a focusable, labelled scroll region that the keyboard can scroll, causes no page-level sideways scroll at 390px, the tag key, what you should have by each gate, link targets and status codes, heading order, no console or CSP errors, WCAG 2.2 AA, and the links to it from `/architect/` and the templates list.

**Accessibility scans (axe-core).** The architect, templates, patterns and document trail checks load axe-core through `tools/axe.js`. It is required: install it next to these scripts with `npm i --no-save axe-core` in `tools/` (or set `AXE_CORE=/path/to/axe.min.js`). If it cannot be found the run fails instead of quietly skipping. Each run prints the axe-core version and file it loaded, and ends with `AXE ran N scans`, so you can see the scans happened. `AXE=off` skips them on purpose and says so.
