Hardware security lifecycle

Hardware assurance checklist

A community checklist for assessing laptops, desktops, peripherals and vendors across the eight-stage lifecycle. Rate each control Achieved, Partially achieved, Not achieved or N/A, using the same discipline as CAF v4.0. This is community guidance, not official NCSC guidance.

Rows marked Enhanced (community-proposed) are a suggested uplift for higher-classification work. They are not an official NCSC profile. The organisation’s security authority may raise, lower or replace them.

    Coverage matrix

    Which controls to assess for each hardware class at each stage. A P means public official guidance is thinner or only indirect — still assess the risk, but do not treat it as a published product standard.

    About the public / private split

    This page holds only the generic community criteria, drawn from public official sources. Programme-specific requirements, evidence and decisions should be held privately by the organisation. Completing this checklist is not official approval, and it is not a substitute for the organisation’s security authority.
