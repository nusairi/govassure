How to read it

The six states are the key states in NIST SP 800-57 Part 1 §7, used here only as a vocabulary. Each state names the lifecycle stages on the model tab that act on it, so you can move between the two. Every transition should be recorded in the key's metadata and audit log.

Overview

A key's life, as states

A key is created in pre-activation, used while active, may be suspended, is deactivated once it should no longer protect new data, and ends destroyed. At any point it can become compromised, and from there it is only ever destroyed.
